## AI 到底是怎么干活的
你每天用的大模型，本质上是一张巨大的神经网络，它读懂你的问题，再一层一层推理出答案。
你给它一句提示词，比如“帮我做一份竞品分析”，它就能直接输出一份完整报告。
数据说话：87% 的重复性办公工作，今天已经可以交给 AI。

## 从工具到 Agent
这三年变化非常快。2022 年 ChatGPT 发布，2024 年多模态开始普及，2026 年 Agent 开始接管整个工作流。
以前你要自己一步一步问 AI，现在多个 Agent 会自己分工协作，检索、规划、写作、审查同时进行。
说白了，AI 不是在替代工具，而是在替代流程。

## 手把手：搭一个知识库
第一步，整理你的文档；第二步，上传到知识库；第三步，用自然语言提问。
[图: ../public/assets/demo-shot.png]
先选一套配色，点击“电光蓝”，再点击“开始拆解”，模板就准备好了。
上传以后，AI 会把文档切成向量存进知识库，你一提问，它就去检索最相关的片段。

## 用代码调用一次
如果你会一点代码，调用它只要几行：
```python
import anthropic
client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "总结这份周报"}],
)
print(msg.content)
```
把它接进自动化流水线，一键批量处理几百份文件。
